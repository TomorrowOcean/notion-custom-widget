# Notion Weather Widget

A single-file weather widget (`index.html`) meant to be embedded in Notion with an **Embed** block.

- Live page: https://tomorrowocean.github.io/notion-weather-widget/
- Weather and city search data come from [Open-Meteo](https://open-meteo.com/) (free, no API key needed).
- Shows current conditions and a 7-day forecast for up to 6 cities. Each viewer's city list is saved in their own browser.
- Follows light/dark mode automatically; add `?theme=light` or `?theme=dark` to the URL to lock it.

## Update

Replace `index.html`, then commit and push to `main`. GitHub Pages redeploys automatically.
